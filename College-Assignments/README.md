# College Assignments

This folder stores coursework organized by academic year and subject.

## Structure

```text
College-Assignments/
├── Year-1/
├── Year-2/
├── Year-3/
└── Year-4/
```

Each subject uses two categories:

- `Code/` — source code, project files, and build configuration needed to understand or reopen coursework.
- `Courseware/` — presentations, documents, study materials, images, and other supporting assets.

## Year 1 Subjects

- `Microcontrollers`
- `Digital-Electronics`
- `Cpp`
- `C-Language`
- `Python`
- `Web-Development`

## Filtering

Development tools, IDE installations, package dependencies, caches, generated build output, executables, installers, and archive packages are intentionally excluded. The original local coursework directory remains the source archive; this repository contains a curated copy.

## Privacy

Personal name and student-ID information were removed from the uploaded directory structure and readable uploaded content.
