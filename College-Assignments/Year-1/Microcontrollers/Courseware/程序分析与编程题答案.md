# 程序分析与编程题答案

## 第1题：程序分析题

原程序把变量 `led` 输出到 P1 口，并通过移位改变 P1 口各位的输出状态。由于题目中常见 LED 接法为低电平点亮，`0xfe` 表示 P1.0 为低电平，其余位为高电平。

1. 程序功能：循环向 P1 口输出变化的数据，使连接在 P1 口的 LED 按一定方向变化显示。需要注意，原程序使用 `led = led << 1;` 后低电平位会逐渐累积，显示效果更接近逐步点亮，而不是严格的单灯流水。
2. `delay` 函数作用：产生软件延时，让 LED 显示保持一段时间。参数 `t` 用来控制外层循环次数，`t` 越大，延时时间越长。
3. `led = led << 1;` 的作用：将 `led` 的二进制位整体左移一位，改变 P1 口各引脚输出状态，从而改变 LED 的亮灭位置。
4. `if(led == 0x00) led = 0xfe;` 的作用：当移位后所有位都变成 0 时，重新赋值为 `0xfe`，使显示过程重新开始。
5. 若要实现灯从右向左移动，可将初值和移位方向改为右移方式。例如低电平点亮、单灯移动时可写成：

```c
unsigned char led = 0x7f;
P1 = led;
delay(500);
led = (led >> 1) | 0x80;
if(led == 0xff)
{
    led = 0x7f;
}
```

原程序的 `delay` 函数中 `for(i = t; i < t; i++)` 条件不成立，实际不会延时，通常应改为 `for(i = 0; i < t; i++)`。

## 第2题：程序填空题

晶振 12MHz 时，MCS-51 一个机器周期为 1us。定时 50ms 需要计数 50000 次，初值为：

`65536 - 50000 = 15536 = 0x3CB0`

2. `0x3c`
3. `0xb0`
4. `1`
5. `1`
6. `1`

## 第3题：程序分析题

1. 该程序使用共阴极数码管。因为数组中 0~9 的段码为 `0x3f、0x06、0x5b...`，这是共阴极数码管常用的高电平点亮段码。
2. `seg_table` 数组用于保存数字 0~9 对应的七段数码管段码。`code` 关键字表示把常量表存放在程序存储器中，节省 8051 片内 RAM。
3. 程序功能：通过 P0 口依次输出 0~9 的段码，使一位共阴极数码管循环显示数字 0 到 9。
4. P0 口作为普通输出口时通常需要外接上拉电阻。因为 8051 的 P0 口为漏极开路结构，输出高电平时需要外部上拉才能得到稳定高电平。
5. 若要实现数字从 9 到 0 倒序显示，可将变量初值设为 9，每次显示后递减，到 0 后重新回到 9。例如：

```c
unsigned char i = 9;
while(1)
{
    P0 = seg_table[i];
    delay(1000);
    if(i == 0)
    {
        i = 9;
    }
    else
    {
        i--;
    }
}
```

原程序的 `delay` 函数中 `for(i = t; i < t; i++)` 同样不会执行，通常应改为 `for(i = 0; i < t; i++)`。
