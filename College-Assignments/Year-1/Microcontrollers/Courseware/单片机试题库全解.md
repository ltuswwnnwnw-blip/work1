> 以大学CS《单片机原理与接口技术》课程（MCS-51/C51）为基准，每题标注**知识点分类**，核心题附**举一反三**拓展。

### 第1题：流水灯程序分析

**原程序（注意：delay函数有严重bug）：**

```c
#include <reg51.h>
void delay(unsigned int t)
{
    unsigned int i, j;
    for(i = t; i<t; i++)  // ★BUG：i=t且i<t永远为假，循环体从不执行
        for(j = 110; j>0; j--);
}
void main()
{
    unsigned char led = 0xfe;
    while(1)
    {
        P1 = led;
        delay(500);
        led = led << 1;
        if(led == 0x00)
            led = 0xfe;
    }
}
```

**(1) 该程序实现了什么功能？**

程序本意实现LED **从右向左逐个点亮**（累计式流水灯）。初始仅P1.0亮(0xFE=11111110)，每次左移后已亮灯位向高位扩展(P1.0→P1.0+1→P1.0+1+2→...)，全部点亮(0x00)后复位重新开始。

但由于delay函数bug，**实际运行时delay不产生延时，LED全亮后立即复位，人眼看到全亮状态而非流水效果**。
**知识点**：⑤ C51程序分析 / ⑨ LED显示 / 调试思维

**(2) delay函数的作用是什么？参数t的作用是什么？**

- **作用**：产生软件延时，消耗CPU时间以控制LED变化速度。
- **参数t**：控制延时时长。**但此delay有严重bug**——正确写法应为 `for(i = 0; i<t; i++)`。
**知识点**：⑤ 函数/延时实现
> **举一反三**：软件延时的本质是让CPU执行无意义循环指令"虚度时间"。51单片机每个空循环约2μs(12MHz)。精确延时需用定时器——软件延时被中断打断不准且浪费CPU。

**(3) led = led << 1;语句的作用是什么？**

将led变量左移一位。0xFE(11111110)→0xFC(11111100)→0xF8(11111000)→...→0xFE，实现亮灯位向左（高位方向）扩展。
**知识点**：⑤ 位运算

**(4) if(led == 0x00) led = 0xfe;语句的作用是什么？**

当所有LED全部点亮(led=0x00)后重置为初始状态(仅最低位亮=0xFE)，实现循环。这是流水灯程序的回环机制。
**知识点**：⑤ 条件分支

**(5) 若要实现灯从右向左移动（单灯循环，非累计），应如何修改？**

**方案A：使用取反+右移（推荐）**
```c
unsigned char led = 0x7F;  // 仅有最高位亮(P1.7)
while(1) {
    P1 = led;
    delay(500);
    led = led >> 1;       // 亮灯位右移
    if(led == 0x00) led = 0x7F;
}
```

**方案B：使用C51库函数_crol_ / _cror_（循环移位）**
```c
#include <intrins.h>
unsigned char led = 0xFE;
while(1) {
    P1 = led;
    delay(500);
    led = _crol_(led, 1);  // 左循环移位1位
}
```

> **举一反三**：`_crol_`和`_cror_`是Keil C51内置循环移位函数，编译后对应RL/RRC汇编指令，效率远超手动移位+条件判断。同时修正delay的bug：将`for(i=t;i<t;i++)`改为`for(i=0;i<t;i++)`。
**知识点**：⑤ 位运算 / ⑨ LED控制 / ⑥ intrins.h

### 第3题：数码管显示程序分析

**(1) 使用的是共阴极还是共阳极数码管？为什么？**

**共阴极数码管**。因段码表中"0"的码值为0x3F=00111111，a~g段全为1(高电平)，共阴极数码管需段选高电平+公共端低电平才能点亮。若为共阳"0"段码应为0xC0(按位取反)。
**知识点**：⑨ 数码管驱动 / ② 段码编码

**(2) seg_table数组的作用是什么？为什么要用code关键字定义？**

- **作用**：存储0~9数字对应的7段数码管段码（查找表/LUT）。通过`P0=seg_table[i]`将数字转换为段码输出。
- **用code的原因**：code将数组存入程序存储器（ROM/Flash），不占用宝贵片内RAM（51仅128/256字节）。段码表是常量，适合放ROM。
**知识点**：⑥ C51关键字(code) / ② 存储器管理
> **举一反三**：嵌入式开发中"用空间换代码"的经典案例——查找表(LUT)技术。不仅是段码，三角函数表、CRC表、字模、正弦波采样表等常量数据都应声明为code。51单片机ROM可达64KB但RAM仅128B，这种权衡是51编程核心思维。

**(3) 该程序实现了什么功能？**

实现0~9数字在数码管上**循环显示**（简易数字秒表效果），每个数字显示约1秒后切换下一个。
**知识点**：⑨ 数码管显示 / ⑤ 程序逻辑

**(4) P0口作为输出口时，通常需要外接什么？为什么？**

**外接上拉电阻**（典型4.7kΩ~10kΩ）。P0口是漏极开路输出（OD），内部无上拉电路，驱动共阴极数码管段选高电平时必须靠外部上拉电阻提供电流，否则只能输出低电平数码管不亮。P1~P3内部已有上拉可省略。
**知识点**：④ I/O端口(P0口特性) / ⑨ 驱动电路

**(5) 若要实现数字从9到0倒序显示，应如何修改程序？**

```c
unsigned char i = 9;       // 从9开始
while(1)
{
    P0 = seg_table[i];
    delay(1000);
    if(i == 0) i = 9;      // 到0后回到9
    else i--;              // 递减
}
```

注意：`unsigned char i`不能用`if(i<0)`判断（无符号数永不<0），改用`if(i==0)`回环。
**知识点**：⑤ 程序修改 / 数据类型陷阱

### 第4题：按键控制LED模式切换（编程题）

**参考程序**：
```c
/*============================================================
 * 第4题：按键控制LED模式切换
 * 硬件：LED→P2口(共阴极，低电平亮)，按键→P1.0(按下低电平)
 * 知识点：⑨按键扫描/消抖 ⑤switch-case ④I/O驱动
 *============================================================*/
#include <reg51.h>
sbit key = P1^0;
#define LED_PORT P2

void delay_ms(unsigned int t)  // 软件延时约1ms
{
    unsigned int i, j;
    for(i = 0; i < t; i++)
        for(j = 0; j < 120; j++);
}

bit key_scan()  // 按键扫描（含消抖+松手检测）
{
    if(key == 0)               // 检测低电平(按下)
    {
        delay_ms(20);          // 延时消抖约20ms
        if(key == 0)           // 再次确认仍按下
        {
            while(key == 0);   // 等待按键释放(松手检测)
            return 1;          // 返回有效按键
        }
    }
    return 0;
}

void main()
{
    unsigned char mode = 0;    // 模式0=全灭,1=全亮,2=奇数,3=偶数
    LED_PORT = 0xFF;           // 初始全灭
    while(1)
    {
        if(key_scan())
        {
            mode++;
            if(mode == 4) mode = 0;
            switch(mode)
            {
                case 0: LED_PORT = 0xFF; break;  // 全灭
                case 1: LED_PORT = 0x00; break;  // 全亮
                case 2: LED_PORT = 0x55; break;  // 奇数(01010101)
                case 3: LED_PORT = 0xAA; break;  // 偶数(10101010)
            }
        }
    }
}
```

**知识点**：⑨ 按键消抖(延时+二次确认+松手检测) / ⑤ switch-case / ④ I/O驱动
> **举一反三**：按键处理三个层次——①消抖(硬件RC或软件延时)；②松手检测(防一次按下触发多次)；③状态机(长按/短按/双击识别)。本程序用`while(key==0)`松手检测缺点：松手前MCU完全阻塞。改进：用定时器中断做按键扫描(每10ms一次)，实现非阻塞按键状态机。

```c
    TL0 = 0x18;
    ET0 = 1; EA = 1;     // 开中断
    TR0 = 1;             // 启动T0
}

void timer0_isr() interrupt 1
{
    TH0 = 0xFC; TL0 = 0x18;    // 重装1ms初值

    // --- 数码管动态扫描(每1ms切换一位) ---
    wei_shi = 1; wei_ge = 1;    // 先关所有位选(消隐防鬼影)
    if(display_pos == 0)        // 显示十位
    {
        P0 = seg_table[second / 10];
        wei_shi = 0;            // 开十位(共阴极低电平有效)
        display_pos = 1;
    }
    else                        // 显示个位
    {
        P0 = seg_table[second % 10];
        wei_ge = 0;             // 开个位
        display_pos = 0;
    }

    // --- 秒计时 ---
    ms_count++;
    if(ms_count >= 1000)        // 1000ms=1秒
    {
        ms_count = 0;
        second++;
        if(second >= 100) second = 0;  // 00~99循环
    }
}

void main()
{
    timer0_init();
    while(1);  // 主循环空闲，一切在中断完成
}
```

**关键设计要点**：

1. **动态扫描在中断中完成**：每1ms切换一位，刷新率=500Hz(每位1ms，2位周期2ms)，远超50Hz视觉暂留阈值，显示稳定无闪烁。
2. **消隐处理**：切换位选前先关所有位选(`wei_shi=1;wei_ge=1`)，避免高位段码短暂出现在低位数码管(鬼影现象)。
3. **1ms中断的多任务复用**：一次中断同时完成数码管扫描和秒计时，体现单定时器多任务复用的嵌入式设计思想。
4. **方式1初值**：65536-1000=0xFC18，验证溢出需1000次计数→1ms。

**知识点**：⑦ 定时器初值计算 / ⑧ 中断服务 / ⑨ 数码管动态扫描 / ⑥ code / ⑤ 程序结构
> **举一反三**：动态扫描本质是时分复用——用高速切换弥补硬件不足。扩展思路：①更多位数码管(如8位)；②矩阵键盘扫描(行输出+列输入定时轮询)；③多任务调度(一个定时器中断驱动多个周期性任务：显示+按键+通信)。但注意：ISR执行时间必须远小于中断间隔，本程序ISR约20μs远小于1ms。
