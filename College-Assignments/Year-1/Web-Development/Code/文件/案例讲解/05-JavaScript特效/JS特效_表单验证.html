一、正则表达式：用符号描述"合法格式"

符号含义例子
^从字符串头开始匹配^a = 以a开头
$到字符串尾结束a$ = 以a结尾
[0-9]任意一个数字(0~9)
[a-z]任意一个小写字母
[A-Z]任意一个大写字母
[0-9A-Za-z]数字+大小写字母都可以
+至少1个[a-z]+ = 至少1个小写字母
*0个或任意个
{n}恰好n个[0-9]{6} = 恰好6位数字
{n,m}n到m个[0-9]{6,12} = 6到12位数字
// 正则表达式基础用法
var reg = /^[0-9A-Za-z]+$/;  // 从头到尾只能出现数字和大小写字母
// /.../ → 正则表达式的边界（就像字符串用""包起来）

reg.test("hello123");   // → true  ✅ 全是数字和字母
reg.test("hello 123");  // → false ❌ 有空格
reg.test("你好");        // → false ❌ 有中文

// 常见验证规则
/^[0-9]*$/                    // 只能输入数字
/^[0-9]{6}$/                  // 恰好6位数字
/^1[3-9][0-9]{9}$/            // 手机号（1开头，第二位3~9，后面9位数字）
/^[0-9A-Za-z]{6,12}$/         // 6~12位的数字或字母（密码）

二、表单提交流程

<form onsubmit="return checkAll()">
    ← onsubmit：表单提交前自动触发
    ← return：把checkAll()的返回值传给onsubmit
    ← checkAll()返回false → onsubmit="return false" → 阻止提交
    ← checkAll()返回true  → onsubmit="return true"  → 允许提交

function checkAll() {
    // && 逻辑"与"：全部为true才返回true
    if (checkUser() && checkPwd() && checkSex() && checkInterest()) {
        return true;   // 全部通过→提交
    } else {
        return false;  // 任一失败→阻止提交
    }
}

四、验证函数链的短路逻辑

checkAll()执行：
  → checkUser() → false? → 后面三个不执行，直接return false
  → checkUser() → true?  → 继续checkPwd()
      → checkPwd() → false? → checkSex()和checkInterest()不执行，return false
      → checkPwd() → true?  → 继续checkSex()
          → checkSex() → false? →checkInterest()不执行，return false
          → checkSex() → true?  → 继续checkInterest()
              → checkInterest() → false? → return false
              → checkInterest() → true?  → return true → 提交！

★ 这就是"短路求值"：遇到第一个false就停，不浪费CPU

五、getElementById vs getElementsByName

getElementById("user")         → 返回单个元素（id是唯一的）
getElementsByName("sex")       → 返回NodeList（name可以重复，radio组必须同名）
getElementsByTagName("input")  → 返回所有input元素的NodeList

六、onsubmit 完整流程图

用户填写表单 → 点击"注册"按钮
  → 触发form的onsubmit事件
  → 调用checkAll()
  → checkAll内部依次调用4个验证函数
  → 每个验证函数独立检查自己的字段
      → 通过 → 显示✅ → return true
      → 失败 → 显示❌错误提示 → return false
  → checkAll汇总结果
      → 全部true → 表单提交 → 跳转到action页面
      → 任一false → 阻止提交 → 用户留在当前页修改

❌ 常见错误：忘了return

onsubmit="checkAll()" → checkAll返回值被丢弃，表单永远会提交！

修复：onsubmit="return checkAll()"（必须加return）
