🕐 JS特效：实时时钟

对应课件 8.3 | 核心：new Date() + switch + setTimeout递归

一、Date对象：JS内置的日历+手表

var now = new Date();  // 创建Date对象，自动保存"此刻"的日期时间
// 注意：new Date()是拍快照，不是实时更新的
// 1秒后再取now.getSeconds()还是创建那一刻的秒数 → 所以要每秒重新new

// Date对象的方法（全部返回数字）：
now.getFullYear();   // → 2026   年份（4位数）
now.getMonth();      // → 6      月份（★0=1月！所以实际月份要+1）
now.getDate();       // → 11     日期（几号）
now.getHours();      // → 14     小时（24小时制，0~23）
now.getMinutes();    // → 30     分钟（0~59）
now.getSeconds();    // → 0      秒（0~59）
now.getDay();        // → 6      星期几（★0=周日, 1=周一 ... 6=周六）

⚠️ 两个大坑

坑1：getMonth()从0开始 → 1月返回0，12月返回11 → 永远要+1才能显示给用户

坑2：getDay()返回数字 → 0~6，不是"星期一" → 需要switch转换成中文

二、switch语句：多分支判断

// switch = 一个变量等于不同值时做不同的事
// 类比：if...else if...else的另一种写法

var day = now.getDay();  // 0~6的数字

switch (day) {
    case 0: weekStr = "星期日"; break;
    case 1: weekStr = "星期一"; break;
    case 2: weekStr = "星期二"; break;
    case 3: weekStr = "星期三"; break;
    case 4: weekStr = "星期四"; break;
    case 5: weekStr = "星期五"; break;
    case 6: weekStr = "星期六"; break;
    default: weekStr = "未知";    // 兜底：万一day不是0~6
}
// ★ 每个case后面必须有break！
// 没有break会怎样？ → 会"穿透"继续执行下一个case
// 例如day=0，没有break → 会一直执行到case 6 → weekStr最终="星期六"
// 这叫switch穿透(fall-through)，基本上都是bug

三、switch vs if 对比

switchif...else if
适用场景一个变量取不同具体值多个条件组合判断
可读性值多时更清晰条件复杂时更灵活
穿透风险忘了break会穿透没有穿透问题
本例中day的值只有6种，switch更好如果day&6且hour>12→if更合适

四、setTimeout递归：每秒刷新自己

function showTime() {
    var now = new Date();         // 每次调用都重新拍快照
    // ... 获取时分秒，显示到页面上 ...
    setTimeout(showTime, 1000);   // 1秒后再次调用自己！
}
// 这招叫"递归调用"——函数自己叫自己
// 和setInterval的区别：
//   setInterval：不管你上次执行完没有，到点就执行
//   setTimeout递归：上次执行完后再等1秒→更稳定
// 为什么用setTimeout而不是setInterval？
//   如果某次执行花了0.5秒，setInterval在1秒后触发→前后两次间隔只有0.5秒
//   setTimeout递归则一定间隔完整的1秒

六、因果关系链

页面加载 → onload触发 → showTime()第一次执行
  → new Date()拍快照 → 提取年月日时分秒星期
  → month+1（因为getMonth从0开始）→ 个位数补零
  → switch把数字转成中文星期
  → 显示到页面上
  → setTimeout(showTime, 1000) → 1秒后再次调用showTime
  → 新的new Date() → 新的秒数 → 页面更新
  → 无限循环 ...

❌ 常见错误：忘了getMonth()+1

症状：7月份显示"6月"

原因：getMonth()返回值是0~11（0=1月），直接显示会少一个月。

❌ 常见错误：switch忘了break

症状：无论星期几都显示"星期六"

原因：没有break → case穿透 → 一直执行到最后一行。
