📂 JS特效：下拉导航菜单

对应课件 8.4 | 核心：HTML嵌套 + CSS父相子绝 + JS控制显示/隐藏

一、HTML结构：嵌套关系

<ul class="nav-bar">
    <li><a href="#">首页</a></li>     ← 没有二级菜单的项
    <li class="has-sub" onmouseover="show(0)" onmouseout="hide(0)">
        <a href="#">产品</a>              ← 一级菜单文字
        <div class="submenu">               ← 二级菜单容器
            <a href="#">手机</a>
            <a href="#">电脑</a>
        </div>
    </li>
    <li class="has-sub" onmouseover="show(1)" onmouseout="hide(1)">
        <a href="#">服务</a>
        <div class="submenu">
            <a href="#">咨询</a>
            <a href="#">售后</a>
        </div>
    </li>
</ul>

二、CSS定位："父相子绝"

/* 父：relative（给子元素当坐标系原点） */
.nav-bar > li {
    position: relative;
}

/* 子：absolute（相对于父元素精确定位） */
.submenu {
    position: absolute;       /* 脱离正常流，相对于最近的relative祖先定位 */
    top: 100%;                /* 父li的100%高度处 → 紧贴一级菜单下方 */
    left: 0;                  /* 和父li左对齐 */
    display: none;            /* 默认隐藏，JS控制显示 */
}

/* 为什么top:100%就能刚好在一级菜单下方？
 * 父li没有设height → 高度由内容撑开 = 一级菜单a的高度
 * 100% = 父li的完整高度 → absolute子元素的top从父li底部开始 */

三、JS交互：显示/隐藏

function show(index) {
    所有二级菜单[index].style.display = "block";  // 显示
}
function hide(index) {
    所有二级菜单[index].style.display = "none";   // 隐藏
}

五、为什么嵌套？——核心设计原理

/* 结构对比 */

/* ✅ 嵌套：二级菜单在li内部 */
<li>
    <a>产品</a>
    <div class="submenu">...</div>  ← 和一级菜单在同一个li里
</li>
/* 鼠标从"产品"移到"手机" → 全程在同一个li内 → 不触发onmouseout */

/* ❌ 分开：二级菜单在外面 */
<li><a>产品</a></li>
<div class="submenu">...</div>  ← 在li外面
/* 鼠标从"产品"移到"手机" → 离开了li → 触发onmouseout → 菜单消失！*/

❌ 常见错误：onmouseout加在一级菜单a上而不是li上

症状：鼠标移到二级菜单时，二级菜单消失了。

原因：mouseout加在a标签上，鼠标从a移到旁边的二级菜单div → 触发a的mouseout。

修复：mouseover/mouseout都加在li上（li包含了a和二级菜单div）。

六、CSS + HTML + JS 协作关系

HTML：提供结构
  └→ nav-bar(ul) > li > a(一级文字) + .submenu(二级容器)

CSS：提供布局和定位
  └→ li { position: relative }          (父相：当锚点)
  └→ .submenu { position: absolute;     子绝：相对父定位
                  top: 100%;            紧贴一级菜单下方
                  display: none; }      默认隐藏

JS：提供交互
  └→ onmouseover → style.display="block"  (显示)
  └→ onmouseout  → style.display="none"   (隐藏)

三者关系：HTML是骨头，CSS是皮肉（长什么样+在哪），JS是神经（什么时候显示/隐藏）
