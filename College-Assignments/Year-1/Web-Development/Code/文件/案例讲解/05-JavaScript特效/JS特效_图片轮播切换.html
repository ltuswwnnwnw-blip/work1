🖼️ JS特效：图片轮播切换

对应课件 8.2 | 核心：定时器 + 鼠标事件 + 透明度联动

一、事件驱动模型

// 鼠标事件：网页知道你在摸哪里
元素.onmouseover = function() { /* 鼠标放上去 */ };
元素.onmouseout  = function() { /* 鼠标移开 */ };

// HTML属性写法（更直观）
<img src="thumb1.jpg" onmouseover="gotoImg(0)" onmouseout="restartAuto()">
// onmouseover → 鼠标经过时触发
// onmouseout  → 鼠标移开时触发

二、完整逻辑链

自动播放模式：
  setInterval(nextImg, 3000)  ← 每3秒自动切下一张
  → nextImg()判断索引号 → gotoImg(索引) → 更新大图src + 更新缩略图opacity

鼠标介入：
  onmouseover → gotoImg(n)直接跳转 + clearInterval暂停自动播放
  onmouseout  → 重新启动setInterval恢复自动播放

为什么鼠标经过时要先clearInterval？
  → 不清理的话：定时器还在倒计时，可能鼠标刚选好图，定时器到期又切走了
  → 用户体验：明明点了第2张，3秒后又跳回自动播放 → 烦死了

三、现场演示

四、定时器生命周期（关键！）

页面加载 → startAutoPlay() → setInterval创建定时器1 → 每3秒切图
    │
鼠标经过缩略图 → gotoImg(n) → clearInterval(定时器1) → 定时器1被杀死
    │                        → 直接跳转到第n张
    │
鼠标移开 → restartAuto() → clearInterval(旧的) → 创建定时器2
    │                    → setInterval创建定时器2 → 重新每3秒切图

★ 如果鼠标经过时不清除定时器：
   定时器1还在倒计时 → 1秒后到期 → 切到下一张
   → 用户刚选的图被覆盖 → 体验很差

❌ 常见错误1：忘记在鼠标事件后重启定时器

症状：鼠标移开后，图片永远停在那张，不再自动播放了。

原因：清除了定时器但没重新创建。

❌ 常见错误2：创建新定时器前没清除旧的

症状：图片切换越来越快，或者跳着切。

原因：每次鼠标移开都创建一个新定时器，旧的没清除，多个定时器同时跑。
