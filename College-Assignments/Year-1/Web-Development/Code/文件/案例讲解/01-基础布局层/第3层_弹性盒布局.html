📖 教学讲解区

📐 第3层：弹性盒布局（Flexbox）

子元素怎么排队——display:flex、flex-wrap、gap、justify-content、align-items

一、flex 三件套 —— 90%的布局就靠这三行

/* ★★★ flex 布局最核心的三行代码 ★★★ */
.container {
    display: flex;        /* ① 开启弹性盒：把子元素变成"弹性项" */
    flex-wrap: wrap;      /* ② 允许换行：一行装不下自动折到下一行 */
    gap: 15px;            /* ③ 统一间距：子元素之间统一留15px */
}
/* 这三行配合 calc() 和 @media，构成了响应式布局的基础 */

❌ 你踩过的坑：第四层媒体查询无效，根子在第三层

现象：写了 @media (min-width: 768px) { li { width: calc((100%-30px)/3); } }，但li还是竖着排，一个占一行。

根本原因：第3层没装 flex-wrap。ul没有display:flex; flex-wrap:wrap，li还是块级元素，不管媒体查询怎么改width，块级元素就是一个占一行。

因果关系链：没写flex-wrap → li保持block → width改了也没用 → 以为是第7层(@media)的问题 → 其实是第3层的问题

二、flex 容器 vs flex 子元素 —— 权力在谁手里

属性写在哪属性做什么

flex-wrap: wrap允许子元素换行

gap子元素之间的统一间距

❌ 你踩过的坑：justify-content 写在非flex元素上无效

旧代码：h2 { text-align:center; justify-content:center; }

问题：h2 不是 flex 容器（没有display:flex），justify-content对非flex元素无效。

修复：先加display:flex，justify-content才生效。

因果关系：justify-content 是 flex 容器的属性 → 元素必须是 display:flex → 否则相当于对牛弹琴

五、flex: 1 —— 占满剩余空间

flex: 1 是flex-grow: 1的简写，意思是："父容器里剩下的空间，都给我"。

固定150px
flex:1（占满剩下的）

左边固定150px，右边自动填满剩余空间→经典的"侧边栏+主内容"布局

六、gap vs margin —— 最终裁决

铁律：flex/grid容器的子元素间距统一用 gap，不要用 margin。

原因：gap 是父容器统一管理，margin 是子元素各自为政。两者同时存在等于两个领导同时下命令。

七、inline-block vs flex —— 时代的对决

inline-block（旧时代）flex（新时代）
谁来控制排列元素自己父容器
换行宽度超过自动折行（不可控）flex-wrap: wrap（精确控制）
垂直对齐默认基线对齐，常对不齐align-items 一行搞定
间距标签间换行符产生4px空隙（难缠）gap 精确控制
推荐仅文字级小元素所有布局场景

八、flex 布局完整模板

/* ===== 第3层：flex布局标准模板 ===== */

/* 卡片网格（响应式基础） */
.card-grid {
    display: flex;           /* 开启弹性盒 */
    flex-wrap: wrap;         /* 允许换行 ← 这是响应式的关键 */
    gap: 15px;               /* 统一间距 ← 子元素不要再设margin */
}

.card {
    width: calc((100% - 30px) / 3);  /* 3列：减2个gap，除以3 */
    /* 注意：calc 运算符两边必须有空格！ */
}

/* 侧边栏 + 主内容 */
.page-layout {
    display: flex;
    gap: 20px;
}
.sidebar { width: 200px; }      /* 固定宽度侧边栏 */
.main-content { flex: 1; }      /* 弹性主内容区，占满剩余 */

九、因果关系链

display: flex → 子元素可以横排 →
flex-wrap: wrap → 一行不够自动换行 →
gap: 15px → 子元素统一间距 →
width: calc((100% - N*gap) / 列数) → 精确控制每列宽度 →
@media 改列数 → 响应式完成

缺了 flex-wrap → 子元素全挤一行 → @media 改width也没用 → 看起来像@media坏了
用了gap又用margin → 间距变大 → calc算错 → 列溢出换行 → 布局崩
