二、类型转换 —— 你之前踩过的坑

❌ prompt() 返回的永远是字符串

var score = prompt("请输入分数");  // 用户输入85
// score 现在是 "85"（字符串），不是 85（数字）！

score + 5;    // → "855"（字符串拼接！不是数学加法！）
Number(score) + 5;  // → 90（先转数字再加）

这和你Python里的 input() 一样——输入永远是字符串。要做数学运算必须先转成数字。

四、逐行因果关系分析

prompt() → 返回字符串 "85"
→ 不转类型直接用 → "85" + 5 = "855"（字符串拼接，不是数学）
→ 用Number()转 → 85 + 5 = 90（数学加法）
→ 用if判断 → 90≥90 → 输出"优秀"

if (条件) {
    条件成立时执行;
} else {
    条件不成立时执行;
}
→ 只会有一种情况被执行，不会同时执行两个分支
→ return 之后函数结束，后面代码不执行

五、JS 和 Python 的函数调用对比

/* Python 调用函数 */
students_input = input_students()      # 无参调用，返回列表
output_students(students_input)        # 有参调用，传入列表

/* JavaScript 调用函数 */
startJudge();                          // 无参调用，不返回值（void）
// 通过onclick事件触发，用户点按钮才执行
// 结果直接写到页面上，不返回值给调用者

六、onclick 事件 —— JS 和 HTML 的"接头方式"

<button onclick="startJudge()">开始判断</button>
<!--
onclick → HTML属性，当用户点击这个按钮时触发
"startJudge()" → 调用我们上面定义的JavaScript函数
这就把HTML（按钮）和JavaScript（逻辑）连接在一起了
-->

💡 核心类比：
HTML = 遥控器（按钮、输入框、文字）
JavaScript = 遥控器里的电路（逻辑、判断、计算）
onclick = 按下按钮 → 电路开始工作 → 结果出现在屏幕上
