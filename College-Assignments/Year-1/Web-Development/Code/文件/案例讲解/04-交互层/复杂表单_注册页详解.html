二、核心知识点拆解

2.1 图标在输入框里——"父相子绝"的经典应用

/* 父：relative（当坐标系原点） */
.icon-input { position: relative; display: inline-block; }

/* 子：absolute（在父容器内精确放图标） */
.icon-input::before {
    position: absolute;
    left: 8px;                    /* 距左8px */
    top: 50%;                     /* 顶部中点 */
    transform: translateY(-50%);  /* 上移自身一半 = 真正垂直居中 */
}
/* 为什么 top:50% 不够？它把图标的顶部放在中心，图标下半截还在下面
 * translateY(-50%) 把图标往上移自身高度的一半 → 图标的中心对齐父容器的中心 */

2.2 padding-left 给图标腾空间

.icon-input input { padding-left: 30px; }
/* 不加这一行 → 图标和输入文字重叠 → 用户打的字被图标挡住 */

2.3 vertical-align: middle —— 内联元素对齐

/* label和input都是inline-block，默认基线对齐 → 对不齐
 * 全部加上 vertical-align: middle → 中线对齐 → 整齐 */
label, input, select { vertical-align: middle; }

三、你踩过的坑

❌ 标签没闭合

<p>文字<p> → <p>不能嵌套，浏览器自动补标签→DOM结构错乱。

修复：<p>文字</p>

❌ </a> 少写斜杠写成 <a>

结果：整个a标签没闭合，后面的元素被吞进这个a里→链接范围异常扩大。
