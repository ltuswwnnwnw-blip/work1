🏗️ CSS 七层体系总览

对应课程：全部章节（3.3 ~ 7.2） |  核心问题：为什么我的 CSS 老是打架？ |  答案：因为你让两个层管了同一件事

一、CSS 的本质不是"一堆属性"，而是"一栋七层楼"

你目前学的所有 CSS 属性，其实分属 七个互不隶属的部门。 就像一栋楼，每层管不同的事： 一楼打地基、二楼定尺寸、三楼管排列、四楼放位置、五楼做装修、六楼搞动画、七楼适配屏幕。

❌ 冲突的本质：你不小心让两个部门管了同一件事。 比如"间距"这件事，二楼的 margin 想管，三楼的 gap 也想管，就打起来了。

✅ 解决方案：写完一行 CSS，先想清楚 "它在第几层？有没有别的层的属性已经在管这件事？" 有的话，删掉一个。

二、七层楼全貌（从上到下）

7 响应式层 —— 不同屏幕怎么变 @media 管辖权：@media 媒体查询、viewport、calc()、min/max-width
6 动效层 —— 怎么动 transition / transform / @keyframes 管辖权：transition过渡、transform变换、animation动画
5 视觉层 —— 长什么样 color / background / shadow 管辖权：颜色、背景、圆角、阴影、渐变、字体
4 定位层 —— 放哪个位置 position / z-index 管辖权：position定位、z-index层级、float浮动
3 排列层 —— 怎么排队 display:flex / grid 管辖权：display、flex-wrap、justify-content、align-items、gap、order
2 间距层 —— 多大、多宽 width / padding / margin 管辖权：width、height、padding、margin、box-sizing
1 重置层 —— 铲平地基 * { box-sizing: border-box } 管辖权：清除浏览器默认样式、统一盒模型

记忆口诀：
一楼打地基（重置），二楼定大小（间距），三楼管排列（flex）， 四楼放位置（定位），五楼做装修（视觉），六楼搞动画（动效），七楼看屏幕（响应式）。

四、最常打架的五对冤家（你踩过的坑都在这里）

冲突对 哪层vs哪层 为什么打架 怎么选
gap vs margin 第3层 vs 第2层 两个属性同时在管"卡片之间的间距"。gap说15px，margin说2px，结果间距变成了15+2+2=19px，而且calc()公式只减了gap忘了margin flex/grid 容器用 gap，子元素不设 margin
width: xx% vs flex: 1 第2层 vs 第3层 width是"你给我多少宽度"，flex是"你把剩余空间分我几份"。两个同时写，浏览器不知道听谁的 固定宽度用 width，弹性比例用 flex，二选一
position: absolute vs flex 第4层 vs 第3层 absolute 的元素脱离第3层的 flex 管理，flex 当它不存在。如果父元素是flex但没有height，absolute子元素会让父元素高度塌成0 absolute 脱离 flex，父元素必须设 relative + height
display: inline-block vs flex 旧第3层 vs 新第3层 inline-block是上世纪的横排方案，flex是现代的。inline-block会有4px幽灵空隙，垂直对不齐 布局用 flex，inline-block 只用于文字级小元素
transform: translate vs margin 第6层 vs 第2层 transform 移动了视觉位置，但原来在第2层占据的空间不变——所以左边留了一个"鬼影空白" 位移用 margin（真动位置），transform 只做动画效果

五、核心铁律：一个职责，只交给一层

铁律1：写之前先问"这是第几层的事"

你要设间距 → 第2层（padding/margin）或第3层（gap），选一个，别两个都用。

你要改排列 → 第3层（flex/grid），别用第2层的margin去推位置。

你要加动画 → 第6层（transition/transform），别用第2层的margin做动画（性能差）。

铁律2：依赖关系从下往上

第1层(重置) → 第2层(间距) → 第3层(排列) → 第4层(定位) → 第5层(视觉) → 第6层(动效) → 第7层(响应式)

每一层依赖于下面所有层。比如第7层的 @media 改宽度，前提是第3层的 display:flex; flex-wrap:wrap 已经装好了。

常见错误：第3层没装 flex-wrap，第7层写媒体查询改li宽度 → 无效，因为li还是块级元素，一个占一行。

铁律3：@media 只覆盖要改的属性

❌ 错误写法：在每个 @media 里把所有CSS重写一遍

✅ 正确写法：默认样式写在外面（小屏），@media 里只写大屏需要改的那几个属性

原因：媒体查询是"覆盖"不是"替换"，重复写不改的属性只会增加代码量和维护成本。

六、写 CSS 前的检查清单（建议贴显示器旁边）

步骤 问题 你在操作哪一层
1 有没有写 * { box-sizing: border-box }？ 第1层（地基必须先铺）
2 这个元素的宽高是固定的还是弹性的？ 第2层
3 它的父元素是 flex/grid 吗？如果是，间距用 gap 不要用 margin 第3层
4 这个元素需要脱离正常流吗（absolute/fixed）？如果是，父元素设了 relative 吗？设了 height 吗？ 第4层
5 样式装饰（颜色、圆角、阴影）是在第5层，不会影响布局吗？ 第5层（通常安全）
6 动效（transition/transform）不会和布局冲突吗？ 第6层（通常安全，但transform注意"鬼影空白"）
7 @media 里只覆盖需要改的属性，不要重复写不需要改的 第7层
