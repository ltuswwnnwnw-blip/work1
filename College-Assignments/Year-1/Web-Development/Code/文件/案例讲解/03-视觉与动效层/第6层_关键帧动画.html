🎞️ 第6层：关键帧动画 @keyframes

不需要hover触发，页面加载就自动播放的动画

一、animation 全家桶属性

/* animation 简写（最常用） */
animation: 名称 时长 时间函数 延迟 次数 方向 填充模式;

/* 拆开写 */
animation-name: bounce;            /* 绑定哪个 @keyframes */
animation-duration: 1s;            /* 持续时长 */
animation-timing-function: ease;   /* 时间函数 */
animation-delay: 0s;               /* 延迟多久开始 */
animation-iteration-count: infinite;/* 播放次数：数字 或 infinite(无限) */
animation-direction: alternate;    /* normal(正向) / alternate(来回) / reverse(反向) */
animation-fill-mode: forwards;     /* 动画结束后停在最后一帧 */

二、四种经典动画演示

1. 弹跳球（bounce + alternate）

@keyframes bounce {
    from { transform: translateY(0); }
    to   { transform: translateY(-100px); }
}
animation: bounce 1s ease infinite alternate;
/* alternate → 正放一遍再反放一遍 = 弹上去又落下来 */

2. 旋转加载圈（spin + linear + infinite）

@keyframes spin { to { transform: rotate(360deg); } }
animation: spin 0.8s linear infinite;
/* linear → 匀速旋转，不会卡顿 */

3. 脉冲呼吸（百分比关键帧）

@keyframes pulse {
    0%   { transform: scale(1);   opacity: 1; }
    50%  { transform: scale(1.2); opacity: 0.7; }
    100% { transform: scale(1);   opacity: 1; }
}
animation: pulse 2s ease-in-out infinite;

4. 左右摆动（transform-origin + rotate）

@keyframes swing {
    0%   { transform: rotate(-30deg); }
    50%  { transform: rotate(30deg); }
    100% { transform: rotate(-30deg); }
}
transform-origin: bottom center;
animation: swing 2s ease-in-out infinite;

三、transition vs animation 对比

transition 过渡animation 动画
触发方式需要触发（:hover等）自动播放
状态数2个（从→到）任意多个（from/to/百分比）
循环不支持infinite 无限循环
来回不支持alternate 来回播放
适用场景按钮hover、卡片悬浮加载圈、轮播图、呼吸灯
