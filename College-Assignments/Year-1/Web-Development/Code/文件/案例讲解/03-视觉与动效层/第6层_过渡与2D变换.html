transition 让变化平滑、transform 让元素变形

一、transition —— 让变化变平滑

/* transition 完整写法 */
transition: 属性名 持续时间 时间函数 延迟时间;

/* 最常用的简写 */
transition: all 0.3s ease;
/* all → 所有可过渡的属性都过渡（颜色、大小、位置、透明度...） */
/* 0.3s → 变化过程持续0.3秒 */
/* ease → 慢→快→慢的节奏（最自然） */

二、transform —— 四大变形

位移
30,-10
旋转45°

倾斜
组合变换
位移+旋转+缩放
transform: translate(30px, -10px);   /* 平移：右移30px，上移10px */
transform: rotate(45deg);              /* 旋转：顺时针45度 */
transform: scale(1.3);                /* 缩放：放大到1.3倍 */
transform: skew(15deg, 5deg);         /* 倾斜：X轴15度，Y轴5度 */

/* 组合变换：空格分隔，从右往左执行 */
transform: translate(20px,0) rotate(20deg) scale(0.9);

⚠️ transform vs margin —— 关键区别

transform: translate() 移动的是视觉位置，原来占据的空间不变——就像一个全息投影，人走了影子还在。

margin 改变的是实际布局位置——人走了空间也腾出来了。

所以：做动画用 transform，改布局用 margin。不要用 transform 来做布局位移。

四、因果关系链

:hover 改属性 → 没写transition → 瞬间跳变 → 生硬
:hover 改属性 → 写了transition:all 0.3s → 平滑过渡

transform移动 → 视觉位置变了 → 原来空间还在 → 旁边有"鬼影空白"
margin移动 → 实际位置变了 → 周围元素重新排列 → 触发重排（性能差）

最佳实践：hover效果用transform+transition（GPU加速，性能好）
         布局位移用margin（真实移动，不欺骗）
