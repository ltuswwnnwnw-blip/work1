三、渐变 —— 不用图片也能做漂亮的背景

/* 线性渐变：从一个方向到另一个方向 */
background: linear-gradient(to right, #3498db, #2ecc71);

/* 对角线渐变 + 三个颜色 */
background: linear-gradient(135deg, #e74c3c, #f39c12, #f1c40f);

/* 径向渐变：从中心向外辐射 */
background: radial-gradient(circle, #fff, #3498db);

四、你踩过的坑

❌ rgba() 参数写了英文单词

旧代码：background-color: rgba(0, green, blue, alpha);

问题：rgba(红, 绿, 蓝, 透明度) 四个参数必须全是数字。你写了 green、blue、alpha 三个英文单词，CSS引擎解析不了，整行丢弃。

修复：rgba(0, 0, 0, 0.3) —— 黑色、30%不透明度。

记法：rgba = Red Green Blue Alpha，全是0-255的数字（Alpha是0-1的小数）。

五、因果关系

rgba参数不是数字 → CSS引擎丢弃整行 → 背景色不生效 → 看不出报错→很难排查
第5层只管"长什么样" → 不影响布局 → 可以放心写，不会和1-4层打架
