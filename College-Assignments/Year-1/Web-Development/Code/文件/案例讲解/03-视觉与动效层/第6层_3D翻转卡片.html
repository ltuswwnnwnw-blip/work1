二、3D翻转的四个必要条件

/* 条件1：父元素设 perspective（透视距离） */
.flip-card { perspective: 800px; }
/* 800px = 眼睛离屏幕的距离，越小3D效果越夸张 */

/* 条件2：翻转容器设 transform-style: preserve-3d */
.flip-card-inner { transform-style: preserve-3d; }
/* ★ 这一行不写，所有子元素的3D变换全部压扁成2D！ */

/* 条件3：正反面都要 backface-visibility: hidden */
.flip-card-front, .flip-card-back { backface-visibility: hidden; }
/* 不写 → 翻过去看到反过来的镜像 → 不是"翻转"是"透视" */

/* 条件4：背面预先 rotateY(180deg) */
.flip-card-back { transform: rotateY(180deg); }
/* 背面默认朝向我们，先翻180°让它背对我们
 * 等hover时整体再翻180° → 背面正好转过来面对我们 */

三、你踩过的坑

❌ 坑1：li没设height，absolute子元素导致塌陷

两个a都是position:absolute→li感知不到子元素→li高度=0→ul也是0→flex布局废了。

修复：li { height: 210px; }手动给高度。

❌ 坑2：z-index层级反了

正面（图片）应该在上层，背面在下层预翻转。你给文字面设了z-index:2→反了。

修复：图片面(last-child)设z-index:2，文字面(first-child)默认下层。

四、因果关系链

没写 perspective → 没有3D空间 → 卡片只能2D缩放，不会翻

没写 transform-style: preserve-3d → 子元素3D变换压扁 → 看不到翻转

没写 backface-visibility: hidden → 翻过去看到反镜像 → 像X光透视

li没写height → absolute子元素让父元素塌陷 → flex布局崩

正面z-index反了 → 默认看到的就是背面 → 翻过去才看到正面 → 本末倒置
