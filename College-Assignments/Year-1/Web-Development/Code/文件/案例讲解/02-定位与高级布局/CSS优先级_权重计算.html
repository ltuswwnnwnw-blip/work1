📖 教学讲解区

⚖️ CSS 优先级 —— 权重计算规则

当多个CSS规则选中同一个元素时，谁说了算？

一、权重计算公式：(ID数, 类数, 元素数)

选择器类型权重值例子计算
行内样式1000style="color:red"直接在标签上写的，最高
ID选择器100#header 100每个ID +100
类/伪类/属性10.box 10 :hover 10每个类 +10
元素/伪元素1div 1 ::before 1每个元素 +1
通配符 *0*不参与权重计算

注意：这不是真正的三位数！11个元素选择器(11)不会超过1个类选择器(10)。

现场演示：看下面这个盒子是什么颜色？

CSS写了：

.priority-demo { background: #3498db; }  /* 权重: 10 (1个类) */
#special-demo { background: #e74c3c; }  /* 权重: 100 (1个ID) */

HTML是：<div class="priority-demo" id="special-demo">

我是红色（#e74c3c），因为 ID权重(100) > 类权重(10)

✅ 结果是红色。虽然.priority-demo写在后面，但#special-demo权重更高。

二、实战计算题（课程里的例子）

#content .book   →  权重 = 100 + 10 = 110   (1个ID + 1个类)
#content span    →  权重 = 100 + 1 = 101    (1个ID + 1个元素)
.book            →  权重 = 10              (1个类)
p span           →  权重 = 1 + 1 = 2       (2个元素)

如果有冲突，#content .book (110) 胜出。

三、!important —— 核武器

⚠️ !important 是最强的，但它不参与权重计算——它直接无视所有权重规则。

多个 !important 之间再比权重。尽量避免使用，因为一旦用了就很难覆盖。

em { color: orange !important; }  /* 无视所有其他color规则 */
p em { color: blue; }             /* 权重101，但被上面的!important覆盖 */

四、优先级来源顺序

当权重相同时：

  1. 行内样式 (style="") —— 权重1000
  2. 内部样式表 (<style>) —— 权重按选择器算
  3. 外部样式表 (<link>) —— 权重按选择器算，后加载的覆盖先加载的

五、最快判断法

遇到"样式不生效"时，按这个顺序排查：

1. 是否被更高权重的选择器覆盖了？（浏览器F12看Computed面板）

2. 选择器是否写错了？（类名拼错、后代关系不对）

3. 是否有 !important 在干扰？

4. calc() 等函数值是否语法错误被丢弃？
