📖 教学讲解区

🌊 浮动布局 —— float与父元素塌陷

float（浮动）是CSS最早的横排方案，现在基本被flex取代，但"父元素塌陷"的问题值得理解

一、float 的两个作用

作用怎么用现在还用吗
文字环绕图片img { float: left; } → 图片在左边，文字在右边环绕✅ 唯一正经用途
多列布局三个div都 float: left → 横着一排❌ 已被flex取代

二、float 的核心问题：父元素塌陷

float 元素脱离正常文档流（类似absolute），父元素感知不到它的高度，导致父元素高度塌成0。

三、清除浮动的三种方法

方法1：clearfix（最推荐）

/* 给浮动元素的父容器加这个类 */
.clearfix::after {
    content: "";          /* 伪元素必须有content，空字符串也行 */
    display: block;       /* 必须是块级元素才能撑开 */
    clear: both;          /* 清除左右两边的浮动 → 父容器感知到高度 */
}

/* 使用 */
<div class="float-parent clearfix">
    <div style="float:left">...</div>
</div>

方法2：overflow: hidden（触发BFC）

.float-parent { overflow: hidden; }
/* 原理：overflow:hidden 触发BFC（块级格式化上下文），BFC会包含浮动子元素
 * 优点：一行搞定
 * 缺点：溢出内容会被裁剪（如果有弹出层会出问题） */

方法3：在末尾加空元素（不推荐）

<div style="clear:both;"></div>  <!-- 多一个无意义的空div，不优雅 -->

四、因果关系链

子元素 float → 脱离文档流 → 父元素感知不到高度 → 父元素塌陷
→ 背景色不显示 → 边框贴在一起 → 下面的内容顶上来

修复：父元素设 clearfix → ::after 插入"清除元素" → 父容器恢复高度

💡 记法：float 让元素"飘"起来了，父元素不知道它多高（就像你跳起来的时候，体重秤读数为0）。clearfix 相当于在最后放一个"不飘的标记"，告诉父元素"这里才是底"。
