📖 教学讲解区

📌 第4层：定位详解

position 五个值：static、relative、absolute、fixed、sticky

一、五种 position 快速对比

值是否脱离文档流相对于谁定位最常用场景
static否（默认）不定位，正常排列所有元素默认就是这个
relative否（保留原位）相对于自己原来的位置给absolute子元素当锚点
absolute是（脱离）最近的有position的祖先徽章、下拉菜单、叠加层
fixed是（脱离）浏览器窗口固定导航栏、回到顶部按钮
sticky否（切换）滚动容器吸顶导航、表格标题冻结

二、relative —— 自己不跑，给别人当锚点

position: relative 有两个作用：

/* 作用1：微调自己的位置（保留原来占的位置） */
.box {
    position: relative;
    top: -10px;    /* 向上偏移10px */
    left: 30px;    /* 向右偏移30px */
}
/* 注意：它本来占的位置还在！下面的元素不会顶上来 */

/* 作用2（更重要）：给 absolute 子元素当"坐标系原点" */
.parent {
    position: relative;  /* 自己不跑，但成为子元素absolute的参考点 */
    /* 不设top/left/right/bottom也行，只需要 relative 这个身份 */
}
.child {
    position: absolute;
    top: 0;
    right: 0;  /* 相对于 .parent 的右上角定位 */
}

三、absolute —— 脱离队伍，精确站位

3.1 absolute 找谁当锚点？

absolute 会向上找最近的有 position 属性（relative/absolute/fixed）的祖先元素作为锚点。
如果一直往上找都找不到，就以 <body> 为锚点——这就是你之前::before背景图飘到页面左上角的原因。

❌ 你踩过的坑：absolute 缺 relative 锚点

旧代码问题：#content::before 设了 position:absolute; left:0; top:0，但 #content 没有 position:relative。

结果：::before 往上找锚点→找不到→找到body→定位到body左上角→背景图飘走了。

修复：#content { position: relative; } 一行解决。

因果关系：absolute找锚点→向上遍历祖先→找到第一个有position的→没有就找body

/* ✅ "父相子绝" —— 最经典的定位组合 */
.parent {
    position: relative;   /* 父：relative，当锚点（自己不跑） */
}
.child {
    position: absolute;   /* 子：absolute，相对于父定位 */
    top: 0;
    right: 0;             /* 贴在父元素的右上角 */
}

/* ❌ 常见错误：忘了给父元素设 relative */
.parent {
    /* 什么都没设 → 子元素的absolute会继续往上找 */
}
.child {
    position: absolute;   /* 会找到更上层的祖先，甚至body */
    top: 0; right: 0;     /* 跑到页面右上角去了！ */
}

3.2 absolute 脱离文档流 → flex 感知不到它 → 父元素塌陷

❌ 你踩过的坑：li 没设高度，子元素 absolute 导致塌陷

旧代码：li 里的两个 a 都是 position: absolute，li 自己没有设 height。

结果：absolute 元素脱离文档流→li感知不到子元素的存在→li高度塌成0→ul也是0→flex布局废了。

修复：li { height: 210px; } —— 手动给父元素设高度，补上absolute子元素"消失"的空间。

四、fixed —— 固定在屏幕上不动

/* 回到顶部按钮——永远在右下角，滚动也不动 */
.back-to-top {
    position: fixed;      /* 相对于浏览器窗口定位 */
    bottom: 30px;         /* 距窗口底部30px */
    right: 30px;          /* 距窗口右边30px */
    z-index: 999;         /* 确保在所有内容上面 */
}

/* 固定顶部导航栏——滚动时导航栏不消失 */
.navbar {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;          /* 横跨整个屏幕宽度 */
    z-index: 100;
}
/* 注意：导航栏fixed后脱离文档流，下面的内容会被导航栏挡住 */
/* 需要给下面的内容加 margin-top 或 padding-top = 导航栏高度 */

五、z-index —— 谁叠在上面

z-index 控制元素的堆叠顺序。数值越大越在上面。但它只在 position 不是 static 的元素上生效。

❌ 你踩过的坑：3D翻转卡片的 z-index 层级反了

问题：正面（图片）应该在上层（z-index高），背面（文字）预翻转180°在下层。

旧代码：给文字面设了 z-index:2，给图片面没设→层级反了。

修复：图片面(last-child)设 z-index:2，文字面(first-child)默认在下层并预翻转180°。

六、因果关系链

子元素 position: absolute
→ 没有 relative 祖先 → 锚点是 body → 定位到页面角落 → 位置不对
→ 有 relative 祖先但父元素没设 height → absolute子元素脱离流 → 父元素塌陷
→ flex容器感知不到absolute子元素 → 布局崩

fix：父元素 { position: relative; height: 固定值; } → 锚点正确 + 空间不塌
